# Amaanallah Gas Connect

Absolutely. For Amaanallah Gas, I would build the website as more than a simple company profile. It should function as a gas-service and delivery platform where customers can learn about services, request LPG delivery, book safety inspections, request installations/maintenance, and contact the business.

Below is a professional Product Requirements Document (PRD) you can use as the blueprint for development.

AMAANALLAH GAS — WEBSITE / SERVICE APPLICATION PRD

Product Name: Amaanallah Gas
Product Type: LPG Gas Delivery & Safety Services Web Application
Version: 1.0
Primary Users: Households, schools, restaurants, hotels, businesses
Platform: Responsive Web Application — Desktop, Tablet & Mobile



1. Product Overview

Amaanallah Gas is an LPG service company providing safe and convenient LPG solutions to households and commercial customers.

The application will allow customers to:

Request LPG delivery
Book gas leakage testing
Request gas cylinder installation
Request installation of safety cages
Purchase/request gas accessories and appliances
Request maintenance of gas appliances
Contact Amaanallah Gas
Learn about LPG safety
Track the status of service requests
The platform will also provide an Admin Dashboard through which Amaanallah Gas staff can manage customers, orders, deliveries, service requests and products.



2. Business Goals

Primary goals

Improve customer communication.

Generate leads from households and businesses.
Eventually provide online ordering and payment.

27. Branding Direction

Based on the Amaana Gas branding you’ve been developing, I’d use:

Primary colors

🟢 Green — safety, energy, reliability
🔵 Blue — trust and professionalism
⚪ White — cleanliness and simplicity

You also mentioned that your gas cylinders are white, green and blue, so the website can use those three cylinder colors as a visual identity.

The design should be clean rather than crowded—large service cards, strong typography, high-quality cylinder/vehicle imagery and plenty of white space.
